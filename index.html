Vizier

MIT

A display-only teleprompter and call overlay any agent can drive over HTTP or MCP.

git clone https://github.com/utopia-models/vizier && cd vizier/server
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python vizier.py   # http://127.0.0.1:8786

Eagle Eye

MIT

One eye on every agent. Each agent's lane on one screen, redrawn every 5 seconds.

curl -fsSL eagleeye.sh/install | sh
# serves the demo on http://localhost:8000

dispatch-runtime

MIT

The dispatch layer of a small agent fleet: one systemd unit per issue, and the flock that closed a 26-27 second cross-user race. Published to be read; it is not a package and will not run unchanged on another host.

git clone https://github.com/utopia-models/dispatch-runtime
# read README.md: the race, the fix, and what was scrubbed
